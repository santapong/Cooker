# Cooker Vercel example service

A dependency-free Node.js Vercel Function with `/api/health`, a native health button and a structured runtime log. No database, durable disk, secret, paid integration or sandbox is provisioned. Use `npm test` for the focused handler check.

Deployment through the Vercel connector and deployment through Cooker are separate receipts. Current Cooker inspection found no running local service at4644, a create-only embedded landing publisher, and no completed generic Vercel deployment-stage/update submission path. The reviewed existing-project update source is preparation only. This example does not bypass that boundary or claim a Cooker-managed run.
