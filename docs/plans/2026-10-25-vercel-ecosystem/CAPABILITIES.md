# Cooker — provider capability map

Checked against the six research reports on **25 October 2026**. Rows describe documented provider offerings and proposed Cooker scope. They do not establish this account's entitlements, installations, provisioned instances, application configuration or successful execution. Product status belongs in the [Cooker ClickUp board](https://app.clickup.com/90181387221/v/l/li/1100540000004771); [TASKS.json](TASKS.json) retains local evidence and the remote mapping. M1 and M3-A have source implementations; executable and live acceptance remain pending.

Read each capability through **offered / installed / provisioned / bound / application-configured / verified** evidence. Record exact account/project/environment/resource IDs, source/time and uncertainty separately. An installation's allowed project access never supplies a resource binding. Credentials and payer belong to explicit account modes; no generic Vercel token reaches every provider.
