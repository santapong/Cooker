✦ getting started

Quick start

Cooker is a single-binary CI/CD platform with a visual DAG editor. Drag stages onto a canvas as planets, wire them into trajectories, and ship OCI images to Kubernetes and cloud runtimes. This guide gets the whole stack running locally in under a minute.

✦

No OIDC required in local mode — Cooker injects a dev admin so you can start building immediately.

Run it locally

The fastest path is the Docker Compose stack. Clone the repo and bring it up:

# clone & launch the full stack git clone https://github.com/santapong/Cooker.git cd Cooker docker compose up

Then open localhost:5173 for the frontend and localhost:8080/api/v1 for the API.

Your first pipeline

  1. Open the Star Map. Head to Pipelines → New pipeline to drop onto the canvas.
  2. Launch planets. Drag a build, test, and deploy stage from the palette.
  3. Draw trajectories. Connect each planet's right port to the next planet's left port.
  4. Run it. Hit Launch run and watch each world light up live.

Pick a builder

Set COOKER_BUILDER to choose how images are built. Kaniko is the secure default — no daemon, no host socket:

export COOKER_BUILDER=kaniko # kaniko | buildkit | buildah | docker export COOKER_PUSHER=crane # OCI distribution-spec v1.1 export COOKER_SECRETS_BACKEND=vault
⚠

The docker builder needs a host socket and is refused at boot in production. Use Kaniko, BuildKit, or Buildah instead.
